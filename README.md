# Last Breath — website

Статический сайт проекта Last Breath на чистом HTML + CSS + JavaScript,
без сборки — можно открывать напрямую или заливать на любой статический хостинг.

## Обновления v9.1 — дисклеймер Mojang
- в футер всех 5 страниц добавлена строка: проект не является официальным
  продуктом Minecraft, не связан с Mojang Studios / Microsoft, не одобрен
  и не спонсируется ими; «Minecraft — товарный знак Mojang Synergies AB».
  Требование прямо прописано в Minecraft Usage Guidelines (Essential
  Requirements) для любого фан-проекта, использующего название игры.

## Обновления v9 — тёмная тема (без «дарк-веба»), Minecraft-флавор, фикс бага
- **найден и исправлен баг**, из-за которого на `rules.html` пропадал весь текст:
  scroll-reveal ждал, пока элемент пересечёт 14% видимости, но `.rules-content`
  (весь свод правил целиком) настолько высокий, что при любой прокрутке
  видна была меньшая доля — порог никогда не достигался, и блок навсегда
  оставался прозрачным. Исправлено на `threshold: 0` (срабатывает от первого
  пикселя пересечения) + подстраховка: через 2.5s всё, что ещё не показалось,
  проявляется принудительно — контент больше не может «потеряться»;
- возврат к тёмной теме, но не к прежнему «дарк-вебу»: вместо холодного
  чёрно-фиолетового — тёплая угольно-зелёная палитра (`#1b1c16` фон,
  зелёный `#6bc24a` + золотой `#e8b23d` акценты вместо лавандового);
- лёгкий Minecraft-флавор: пиксельный акцентный шрифт (Pixelify Sans) для
  крупных заголовков (hero, page-hero, section h2), «бевельные» кнопки и чипы
  (inset-тени имитируют объёмные пиксельные кнопки, с обратным bevel на
  :active — «нажатие»), дизерная зелёная полоска под шапкой на каждой
  странице. Тело текста и список правил намеренно оставлены на Archivo —
  пиксельный шрифт не годится для длинного чтения;
- цвета статусов/меток (онлайн/оффлайн/скоро, наказания в правилах)
  адаптированы под тёмный фон.

## Обновления v8 — светлая тема + реальные правила
- полный переход с тёмной на светлую палитру (по просьбе — «не тёмный интернет,

  сине-фиолетовый градиент из настоящей иконки сервера;
- убран WebGL-звёздный фон и зернистость — вместо них мягкие размытые
  цветные пятна («aurora blob»), дышащие в том же ритме, что и раньше;
- в шапку и favicon встроена реальная иконка сервера (`assets/server-icon.png`),
  добавлен `og:image`;
- `rules.html` полностью переписан — вставлен настоящий свод правил проекта
  (разделы I, II, III, IV, VII, VIII, ~90 пунктов) со сноской-оглавлением
  для навигации и разметкой «Примечание / Наказание» под каждым пунктом;
- `script.js` заметно упрощён (убран WebGL-код звёзд и метеоров), логика
  статуса/копирования/меню/scroll-reveal не тронута.

## Обновления v7 — визуальный проход
- фирменный приём: медленное «дыхание» (6s, вдох-выдох) на ambient-глоу в hero
  и page-hero, на статус-индикаторах онлайна и на маркере перед kicker-лейблами —
  единый мотив вместо разрозненных эффектов, буквально отсылающий к названию;
- скролл-reveal: карточки режимов, feature-card и текстовые блоки плавно
  проявляются при попадании во вьюпорт (`IntersectionObserver`, с фолбэком
  и `<noscript>` на случай отключённого JS);
- вход контента hero / page-hero при загрузке страницы (лёгкий staggered fade+rise);
- ghost-нумерация разделов — крупная полупрозрачная цифра-водяной знак за
  section-intro, генерируется CSS-counter'ом (`counter(sect)`), без правок разметки;
- уточнённые hover-состояния: server-row получил акцентную левую полосу,
  feature-card — заливку и подсветку заголовка, nav-ссылки — анимированное
  подчёркивание, кнопки — лёгкий tap-scale;
- тонкая плёночная зернистость (film grain, SVG-текстура) поверх сайта для
  кинематографичности;
- стилизованный скроллбар, ::selection, :focus-visible — под акцентный цвет;
- favicon (инлайн SVG) и OG/Twitter-теги на всех страницах;
- анимация открытия мобильного меню (fade + stagger по пунктам);
- всё новое уважает `prefers-reduced-motion` — анимации отключаются,
  контент остаётся видимым.

## Обновления v6
- звёздный фон переведён на WebGL: 100 точек (фикс. количество), рендер
  одним draw call'ом (`gl.POINTS`) вместо CPU-отрисовки в canvas2d;

## Структура
- `index.html` — главная
- `modes.html` — режимы (текущие и в разработке)
- `status.html` — статус серверов в реальном времени
- `rules.html` — правила проекта
- `about.html` — о проекте
- `style.css`
- `script.js` — навигация, копирование IP, виджет статуса, звёздный фон
